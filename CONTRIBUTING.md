# Contributing to CargoWare CRM

Thank you for your interest in contributing! This project welcomes contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/-cargoware-crm.git`
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature`
5. Start the dev server: `npm run dev`

## Development Workflow

- Make your changes in the feature branch
- Test locally with `npm run build && npm run preview`
- Commit with descriptive messages
- Push and open a Pull Request against `main`

## Code Style

- Follow existing patterns in the codebase
- Use functional components with React hooks
- Keep components focused — split into sub-components when exceeding ~200 lines
- Use Ant Design components consistently with the existing theme

## Reporting Issues

Open an issue with:
- Clear description of the problem
- Steps to reproduce (if applicable)
- Expected vs actual behavior
- Browser/environment info
